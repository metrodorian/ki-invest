# ki-invest

Recherche und Strategieüberlegungen zu einer Short-Wette auf die These: **Die westlichen KI-Investitionen (~2 Billionen USD) erzeugen kaum Gegenwert, während China mit günstigerer, subventionierter Hardware/Energie im KI-Wettbewerb aufholt oder gewinnt.**

Kein Anlageberatungs-Dokument — reine Sammlung von Recherche, Produktoptionen und offenen Fragen als Entscheidungsgrundlage.
